If you have worked with point maps in Qlik, you are probably familiar with how selections normally work. You zoom into an area, use the lasso tool to draw around the points you want, confirm the selection, and repeat the process if you want to explore somewhere else. Qlik Cloud now supports another option for point layers called Auto select visible : Instead of manually selecting points, you move around the map and Qlik updates the selection based on the area you are viewing.
