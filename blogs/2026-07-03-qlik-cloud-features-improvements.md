Highlights three new Qlik Cloud capabilities: subtotals within straight tables (previously pivot-table only), a new Exit Error feature for script error handling with custom messaging, and a streamlined way to generate text and image objects by pasting content directly onto sheets, with pasted images auto-saved to the media library.
